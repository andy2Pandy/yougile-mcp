# YouGile MCP Server

MCP сервер для интеграции с YouGile. Работает с любыми AI помощниками, поддерживающими протокол MCP (Claude Desktop, Continue, Cline и другие). Позволяет AI работать с вашими проектами, задачами и командой в YouGile.

## ChatGPT Work в браузере

Веб-версия ChatGPT не запускает локальные stdio-серверы. Для неё этот форк
поддерживает удалённый **Streamable HTTP MCP** и готов к развёртыванию на Render.

Безопасный режим пилота включён по умолчанию:

- используется только `YOUGILE_API_KEY`, логин и пароль на сервер не передаются;
- `YOUGILE_READ_ONLY=true` блокирует создание, изменение и удаление объектов;
- удалённые инструменты управления API-ключами отключены;
- `MCP_URL_TOKEN` добавляет секретный сегмент в адрес MCP.

### 1. Подготовьте YouGile

Создайте отдельный API-ключ YouGile с доступом к нужной компании и скопируйте
`Company ID`. Для первого теста рекомендуется использовать только 1–2 проекта.
Не публикуйте ключ в GitHub и не отправляйте его в чат.

### 2. Разверните на Render

1. В Render выберите **New → Blueprint**.
2. Подключите этот GitHub-репозиторий и файл `render.yaml`.
3. Когда Render запросит секреты, заполните:
   - `YOUGILE_API_KEY` — API-ключ YouGile;
   - `YOUGILE_COMPANY_ID` — ID компании;
   - `MCP_URL_TOKEN` — длинная случайная строка без пробелов, например UUID.
4. Дождитесь статуса **Live**.

Адрес MCP будет выглядеть так:

```text
https://<имя-сервиса>.onrender.com/<MCP_URL_TOKEN>/mcp
```

Открывать этот URL в обычной вкладке браузера не требуется: это протокольная
точка MCP, а не веб-страница.

### 3. Создайте приложение ChatGPT

1. В ChatGPT включите **Settings → Security and login → Developer mode**.
2. Откройте **Settings → Plugins**, нажмите `+` и создайте developer-mode app.
3. В качестве MCP URL укажите адрес из предыдущего шага.
4. После создания скопируйте идентификатор приложения из URL страницы. Он
   начинается с `plugin_asdk_app_`.

По этому идентификатору можно собрать персональный плагин ChatGPT Work.

> Секретный сегмент URL — защита для личного read-only пилота, но не замена
> полноценному OAuth. Не включайте запись и не делитесь URL до добавления OAuth.

### Включение записи после пилота

После проверки read-only сценариев можно установить на Render:

```text
YOUGILE_READ_ONLY=false
```

До этого момента любые инструменты создания и изменения возвращают ошибку и
не отправляют изменяющие запросы в YouGile.

## 📦 Установка

### 1. Скачайте проект
```bash
git clone https://github.com/andy2Pandy/yougile-mcp.git
cd yougile-mcp
```

### 2. Создайте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Получите данные YouGile

Создайте API-ключ YouGile. Логин и пароль нужны только для необязательного
локального режима автоматического создания ключа и не рекомендуются для
постоянной конфигурации.

**Получите ID компании:**
1. Войдите в [YouGile](https://yougile.com)
2. Нажмите `Ctrl + ~` для открытия конфигуратора
3. Перейдите во вкладку "Навигатор по объектам" справа
4. Нажмите на иконку информации (ℹ️) справа от названия вашей компании
5. Скопируйте ID компании из открывшегося окна

### 5. Подключите к AI помощнику

**Для Claude Desktop:**

Добавьте в конфигурацию Claude Desktop:
```json
{
  "mcpServers": {
    "yougile": {
      "command": "python",
      "args": ["/полный/путь/к/папке/yougile-mcp/run_server.py"],
      "cwd": "/полный/путь/к/папке/yougile-mcp",
      "env": {
        "PATH": "/полный/путь/к/папке/yougile-mcp/venv/bin:$PATH",
        "YOUGILE_BASE_URL": "https://yougile.com",
        "YOUGILE_API_KEY": "ваш-api-key",
        "YOUGILE_COMPANY_ID": "ваш-company-id",
        "YOUGILE_READ_ONLY": "true"
      }
    }
  }
}
```

**Для других MCP-совместимых AI:**

Используйте аналогичную конфигурацию для Continue, Cline и других MCP-совместимых помощников.

## ⚙️ Диагностика проблем

### Проверка работы сервера
```bash
# Убедитесь что виртуальное окружение активировано
source venv/bin/activate  # На Windows: venv\Scripts\activate

python run_server.py
```
Сервер должен запуститься и подключиться к YouGile автоматически.

### Частые ошибки

**"No module named 'mcp'"** - не активировано виртуальное окружение. Выполните `source venv/bin/activate`

**"No module named 'src'"** - запускайте через `python run_server.py`, не напрямую `src/server.py`

**"HTTP 401"** - неверные данные для входа в YouGile

**"HTTP 403"** - нет доступа к компании

### Получение помощи
Если что-то не работает:
1. Проверьте, что можете войти в YouGile через браузер с теми же данными
2. Убедитесь, что Company ID правильный (см. инструкцию выше)
3. Попробуйте запустить `python run_server.py` напрямую и посмотрите на вывод
